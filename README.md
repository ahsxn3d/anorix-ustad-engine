# Ustad Engine

Concept site for an AI study platform: a tutor that asks before it tells, checks your working line by line, and schedules reviews of what you found hard.

Stack: Next.js 16 · React 19 · Tailwind CSS 4 · GSAP · Lenis. Fonts: Fraunces, Inter, JetBrains Mono (OFL).

```bash
npm install
npm run dev   # http://localhost:3018
```
